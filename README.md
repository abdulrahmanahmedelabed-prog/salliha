## المميزات

### 🏪 لكل أنواع المحلات
عند أول تشغيل تختار نوع محلك، ويتكيّف البرنامج بالكامل (ويمكن تغييره من الإعدادات):

| | 📱 جوالات وتابلت | 💻 لابتوبات وكمبيوتر | 📺 إلكترونيات |
|---|---|---|---|
| الماركات المقترحة | Samsung، iPhone، Xiaomi، Huawei، Oppo… | Dell، HP، Lenovo، Asus، MacBook، MSI… | شاشات، PlayStation، Xbox، طابعات، راوترات، سماعات… |
| حقول إضافية | السعة، اللون | المعالج، الرام، التخزين، النظام، نسخ البيانات | نوع الجهاز، المقاس |
| أعطال بضغطة | شاشة، بطارية، شحن، Face ID، iCloud… | سخونة، كيبورد، باور جاك، فورمات، ترقية SSD/RAM، BIOS… | إضاءة خلفية، HDMI، باور/بوردة، يد التحكم… |
| فحص الاستلام | ظهر مكسور، إطار معوج… | مفصلات، أزرار ناقصة، براغي، ملصقات الضمان… | أجزاء ناقصة، رائحة حريق… |

محل «الكل» يختار نوع الجهاز لكل طلب، مع تصفية وتقرير حسب النوع، ويتذكر البرنامج آخر نوع استخدمته.

### 📋 الطلبات
- استلام جهاز في ثوانٍ: رقم الهاتف يملأ اسم العميل تلقائياً، واقتراحات للأعطال الشائعة وأنواع الأجهزة.
- 8 حالات من الاستلام حتى التسليم، مع **عرض قائمة** و**لوحة كانبان** بالسحب والإفلات.
- أولوية «مستعجل»، موعد تسليم مع تنبيه **المتأخر**، وتوزيع على **الفنيين**.
- بطاقات سريعة قابلة للنقر: استلام اليوم، قيد العمل، جاهز، متأخر، مبالغ متبقية.
- بحث فوري بالاسم أو الهاتف أو الجهاز أو IMEI أو رقم الطلب.

### ✅ الفحص عند الاستلام (حماية للمحل)
- قائمة المستلم مع الجهاز (شاحن، كفر، شريحة، ذاكرة…).
- حالة الجهاز عند الاستلام (خدوش، كسر، تلف سوائل، مفتوح سابقاً…).
- رمز القفل، **صور الجهاز** بالكاميرا، و**توقيع العميل** على الشاشة.

### 💰 المال والمخزون
- دفعات متعددة (نقداً، تحويل، بطاقة، محفظة) مع عربون عند الاستلام و«سداد الباقي».
- **مخزون قطع الغيار**: يُخصم تلقائياً عند استخدام القطعة ويُعاد عند الحذف، مع تنبيه النقص.
- **ربح حقيقي لكل طلب** = السعر − تكلفة القطع.

### 💵 الصندوق
- **بيع مباشر** للإكسسوارات وقطع الغيار مع خصم وفاتورة مطبوعة، ويُخصم من المخزون تلقائياً.
- **المصروفات** (إيجار، كهرباء، رواتب، مشتريات…) ليكون الربح في التقارير **صافياً حقيقياً**.
- **إغلاق اليوم**: تحصيل الصيانة + المبيعات − المصروفات، موزّعاً حسب طريقة الدفع، مع طباعة تقرير الإغلاق.

### 🛡️ الضمان
- مدة ضمان لكل طلب تبدأ من تاريخ التسليم.
- عند استلام جهاز يُكشف تلقائياً إن كان **ضمن الضمان** (بالـIMEI أو الهاتف والجهاز).

### 🖨️ الطباعة
- إيصال احترافي بشعار المحل و**باركود** ورقم الطلب والشروط والتوقيع — لطابعات 58مم و80مم الحرارية أو A4.
- **ملصق للجهاز** 50×30مم بالباركود واسم العميل ورمز القفل.

### 💬 واتساب
- رسالة جاهزة لكل حالة بضغطة واحدة، قابلة للتعديل من الإعدادات، مع متغيرات مثل {الاسم} و{المتبقي}.
- عند تغيير الحالة إلى «جاهز» يقترح إرسال إشعار للعميل.

### 👥 العملاء
- قاعدة عملاء تلقائية مع سجل كل عميل، إجمالي ما دفعه، ديونه، وشارة «عميل دائم».

### 📊 التقارير
- الإيراد المحصّل، تكلفة القطع، صافي الربح، متوسط الفاتورة، متوسط مدة التصليح، ديون العملاء.
- رسم بياني يومي/شهري، وتوزيع حسب الحالة والأجهزة والأعطال وأداء كل فني.

### ☁️ المزامنة وتتبّع العميل
- **مزامنة تلقائية** بين كمبيوتر المحل وجوالات الفنيين: كل طلب، عميل، قطعة، صورة وإعداد — كل 30 ثانية وعند كل تعديل، ويستمر العمل دون إنترنت ثم يُزامن عند عودته.
- **صفحة تتبّع لكل جهاز**: يفتحها العميل من رابط واتساب أو من **QR على الإيصال** ويرى مراحل التصليح، الموعد، المبلغ المتبقي، والضمان — دون أن يتصل بك.
- الصفحة لا تعرض رقم هاتف العميل ولا ملاحظاتك الداخلية أو رمز قفل الجهاز.

### 🔒 البيانات والأمان
- يعمل **بالكامل دون إنترنت**، والبيانات على جهازك فقط (لا اشتراك شهري).
- رمز دخول للتطبيق.
- نسخة احتياطية كاملة (مع الصور) واسترجاعها، وتصدير الطلبات إلى Excel.
- الوضع الليلي تلقائياً، وواجهة عربية بالكامل مُصممة للجوال والكمبيوتر.
- اختصارات: <kbd>N</kbd> طلب جديد، <kbd>/</kbd> بحث.

## ☁️ تشغيل خادم المزامنة والتتبّع

المزامنة وصفحة التتبّع تحتاجان خادماً صغيراً واحداً للمحل (أو لعدة محلات). الخادم بلا مكتبات خارجية ويخزّن في SQLite.

**الخيار 1 — Render (الأسهل):** أنشئ حساباً على [render.com](https://render.com)، ثم New ← Blueprint واختر هذا المستودع؛ سيقرأ `render.yaml` ويشغّل الخادم مع قرص دائم للبيانات (خطة Starter مدفوعة لأن القرص الدائم غير متاح مجاناً). ستحصل على عنوان مثل `https://salliha-xxxx.onrender.com`.

**الخيار 2 — أي سيرفر VPS بـ Docker:**
```bash
docker build -t salliha .
docker run -d --restart=always -p 8080:8080 -v salliha-data:/data --name salliha salliha
```
ضعه خلف https (مثلاً Caddy أو Cloudflare Tunnel) — تطبيق أندرويد يرفض الاتصال بخادم http.

**الخيار 3 — بدون Docker:** `node --no-warnings server/server.js` (يحتاج Node 22.13 أو أحدث). المتغيرات: `PORT` و`DATA_DIR`.

**ثم في التطبيق:** الإعدادات ← المزامنة ← أدخل عنوان الخادم ← «إنشاء حساب للمحل». انسخ **رمز المزامنة** وأدخله في باقي أجهزتك عبر «ربط بحساب موجود».

> الخادم يقدّم أيضاً نسخة الويب من التطبيق على عنوانه الرئيسي، فيمكن استخدامه من أي متصفح.
> احتفظ بنسخة من مجلد `/data` — فيه كل بيانات المحلات.

**ملاحظات:** إن عدّل جهازان نفس الطلب قبل المزامنة يُعتمد آخر من زامن. لكل جهاز رقم ثابت في ترقيم الطلبات (`S-2026-0012` للأول، `S-2026-2-0012` للثاني…) فلا يتكرر رقم طلب حتى لو عملت الأجهزة دون إنترنت.

## للمطورين

```bash
npm test             # 12 اختباراً: الخادم + الواجهة كاملة في متصفح حقيقي (يتطلب: npm i --no-save playwright && npx playwright install chromium)
```
كل push يشغّل الاختبارات أولاً، ولا يُبنى أي إصدار إن فشل أحدها.

**توقيع أندرويد:** يُوقَّع APK بمفتاح ثابت (`native/android/salliha.keystore`) حتى تُحدَّث النسخ فوق بعضها. للنشر التجاري أو على Google Play أنشئ مفتاحاً خاصاً وضعه في أسرار المستودع `ANDROID_KEYSTORE_B64` و`ANDROID_KEYSTORE_PASSWORD` (الاسم المستعار `salliha`) — سيُستخدم تلقائياً بدل المرفق.

```bash
npm install
npm start            # تشغيل نسخة ويندوز (Electron)
npm run dist:win     # بناء ملف التثبيت في dist/
```

أندرويد (Capacitor): `npm run icons && npx cap add android && cp native/android/MainActivity.java android/app/src/main/java/com/salliha/app/ && npx cap sync android` ثم افتح مجلد `android` في Android Studio.

نسخة الويب: شغّل `www/start.ps1` أو أي خادم ثابت على مجلد `www`.

كل push على `main` يبني تلقائياً ملفات Windows وAndroid وينشرها في [الإصدارات](https://github.com/abdulrahmanahmedelabed-prog/salliha/releases) (`.github/workflows/build.yml`).
